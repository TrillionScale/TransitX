# TransitX
TransitX — AI-powered borderless transit, payment &amp; FX infrastructure on XRPL. Built for Korea Financial Innovation Program 2026.
> AI-powered borderless transit, payment & FX infrastructure on XRPL.

TransitX는 외국인이 현지 교통 및 금융 시스템을 이용할 때 겪는 구조적
문제를 해결하기 위해 설계된 차세대 글로벌 모빌리티·결제 인프라입니다.

## Key Features
- 🤖 AI multimodal recognition for persistent identity
- 💱 Atomic FX settlement on XRPL DEX
- ⚡ Sub-5s payment finality with low fees
- 🔐 Privacy-preserving identity layer

## Tech Stack
- **Blockchain**: XRPL (Testnet)
- **Frontend**: Next.js (PWA), Web NFC API
- **Backend**: Node.js, xrpl.js
- **AI**: Multimodal recognition
